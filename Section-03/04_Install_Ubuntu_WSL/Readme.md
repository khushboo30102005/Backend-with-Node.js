# Install Linux (wsl -- Windows Subsystem for Linux)
Linux is a free, open-source, **Unix-like operating system (OS)** based on the **Linux kernel**, originally released by *Linus Torvalds in 1991*. It acts as an intermediary between hardware and software, powering everything from supercomputers and servers to smartphones (Android) and embedded devices. Known for its security, stability, and flexibility, Linux allows users to modify and redistribute the code freely. 

What Is Windows Subsystem for Linux? Windows Subsystem for Linux (WSL) is a Microsoft-developed compatibility layer that ***allows users to run a native Linux environment—including command-line tools, utilities, and applications—directly on Windows 10/11 and Windows Server***. It eliminates the need for traditional virtual machines or dual-boot setups, offering high performance and deep integration between Windows and Linux file systems.
