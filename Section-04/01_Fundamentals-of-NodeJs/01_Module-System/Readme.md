## What is the `Module System` in Node.js :

The `Module System` in node.js is the **mechanism that let's us split our code into reuseable files (Modules) and `import/export` functionality between them.**

- Instead of writing everything in one giant file, organize code into small, manageable pieces.

- Why do we need a module system?

  Because it helps with:

  ✅ **Code reusability**

  ✅ (**Better organization**)

  ✅ **Maintainability**

  ✅ **Avoiding global variable pollution**

  ✅ **Team collaboration**
