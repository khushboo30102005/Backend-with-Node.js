# Different Types of Modules :

### Classification by Source

#### Node.js modules are generally classified into **three types based on where they originate**:

### Core (Built-in) Modules: 
 These modules are compiled into the `Node.js binary` and are available for use **without any installation**. They provide essential functionalities like file system operations (`fs`), HTTP handling (`http`), and path utilities (`path`).

### Local (Custom) Modules:
 These are modules **created by developers within a project** to organize application-specific logic into separate, manageable files. They help in encapsulating functionality and improving code reusability.

### Third-Party Modules:
 These modules are **developed by the community and published to the npm (Node Package Manager) registry**. They are installed using npm (e.g.  `npm install express`) and are located in the `node_modules` directory. Examples include `Express.js` or `Lodash`.
