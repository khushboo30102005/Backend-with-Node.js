# DIGITAL DATA UNITS :

Digital data units `measure storage capacity and transmission speeds`, starting from the smallest unit, the bit (0 or 1).

### SI Units (Decimal/Metric): `International System of units`

SI uses decimal base 10 prefixes (`Kilo = 10^3` and `Mega = 10^6`) for SI units like bytes. Based on powers of 10. SI is used for general measurement (meters, grams).

`1 kilobyte (kB) = 1,000 bytes`.

### IEC Units (Binary): `International ElectroTechnical  Commission`

- Based on powers of 2. 

- 1 kibibyte (KiB) = 1,024 bytes.
- defines binary base-2 prefixes (kibi=2^10, mebi= 2^20) for data storage, such as KiB or MiB, to avoid ambiguity between
and 1000 and 1024.
