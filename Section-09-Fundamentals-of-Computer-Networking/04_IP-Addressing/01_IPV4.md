# IPV4 Address:

`IPV4` **(Internet Protocol Version 4)** is unique numeric identifier assigned to every device connected to a network.

An `IPV4` address is used to identify a devices and help data reach the correct destination over the internet.

## 📌 Format of IPv4 Address

It is written in 32-bit format, divided into 4 parts (octets)

#### 👉 Example:

`192.168.1.1`

- Each part ranges from 0 to 255
- Total = 4 numbers separated by dots

### 📌 Representation:

- Human-readable (Decimal):

```js
xxx.xxx.xxx.xxx (e.g., 192.168.1.10)
```

- Machine-readable (Binary):

```js
00000000 00000000 00000000 00000000
```

**👉 Each `xxx` = 8 bits → total = 32 bits**

## 🔹 3. Subnet Mask

**A Subnet Mask is also a 32-bit number**

- #### It divides an IP address into:

1. Network Portion (fixed)
2. Host Portion (variable)
   **📌 Example:**

```js
IP Address: 192.168.1.10
Subnet Mask: 255.255.255.0
```

**📌 Binary:**

```js
Subnet Mask:
11111111.11111111.11111111.00000000
```

**👉 Meaning:**

First 24 bits → Network
Last 8 bits → Host

## 🔹 4. IPv4 Address Range

```js
Minimum: 0.0.0.0
Maximum: 255.255.255.255
```

## 🔹 5. Reserved Address Range

**🔸 Loopback Addresses:**
```js
Range: 127.0.0.0 – 127.255.255.255
```
**Used for: Testing and internal communication**

***📌 Important:***
```js
127.0.0.1 → Localhost (your own machine)
Subnet Mask: 255.0.0.0
```
