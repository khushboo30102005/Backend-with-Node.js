# ✅ Benefits and Drawbacks of Public and Private IP Addresses

## 🟩 Benefits of Public IP Address
- Can be accessed from anywhere on the internet  
- Used by servers for direct communication  
- Enables global connectivity and remote access  

## 🟥 Drawbacks of Public IP Address
- Limited number of IPv4 addresses → IP pool exhaustion  
- Exposed to the internet → vulnerable to attacks (e.g., DDoS)  
- Usually paid (provided by ISP)  

---

## 🟩 Benefits of Private IP Address
- Helps reduce exhaustion of public IP addresses  
- Used only within a Local Area Network (LAN)  
- More secure (not directly exposed to the internet)  
- Safe for internal communication  

## 🟥 Drawbacks of Private IP Address
- Cannot access the internet directly  
- Requires a Public IP (via NAT) for internet communication
