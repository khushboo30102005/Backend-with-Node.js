## IPV6 Address:

**An IPv6 address is a 128-bit alphanumeric label used to identify a device on an IPv6 network**, designed to replace IPv4 by providing a vastly larger address space. **It consists of eight 16-bit hexadecimal segments separated by colons** (e.g., `2001:db8:0:0:0:ff00:42:8329`), which can be shortened using `::` for consecutive zeros.

### Key Characteristics and Format

- **Structure**: Eight groups of four hexadecimal digits (e.g. `2001:0db8:85a3:0000:0000:8a2e:0370:7334`).

- **Compression**: Leading zeros in a group can be omitted, and a single contiguous run of zero-value segments can be replaced with `::`. For instance, `2001:db8::ff00:42:8329`.

- **Types**: Defines Unicast (single interface), Multicast (group of interfaces), and Anycast (nearest node in a group) addresses.

- **Components**: An IPv6 address consists of a network prefix (usually the first 64 bits) and an interface identifier (the remaining 64 bits).

### IPv6 vs. IPv4

- **Size**: 128-bit length vs. 32-bit (IPv4).
- **Format**: Hexadecimal (0-9, a-f) vs. Decimal (0-9).
- **Header**: Fixed 40-byte header, reducing processing overhead compared to the variable length of IPv4 headers.

### Common IPv6 Address Examples

- **Loopback Address**: `::1` (equivalent to `127.0.0.1`).
- **Default Route**: `::/0`.
- **Global Unicast**: `2000::/3 `(routable on the internet).
- **Unique Local Address (ULA)**: `fc00::/7` (used for private, internal networks)

### way to write IPV6:

`2001:0db8:85a3:0000:0000:8a2e:0370:7334` -> `2001:db8:85a3::8a2e:370:7334`

`2001:0000:0000:0db8:85a3:0000:0000:7334` -> `2001::db8:85a3:0:0:7334`

`0000:0000:0000:0000:0000:0000:0000:0000` -> `::`

`0000:0000:0000:0000:0000:0000:0000:0001` -> `::1`
