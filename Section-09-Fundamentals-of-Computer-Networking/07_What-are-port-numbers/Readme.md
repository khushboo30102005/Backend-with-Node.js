## 🌐 What is a Port Number?

**A port number is a logical identifier used in networking to specify which application or service on a device should receive the data.**

## 🔍 Technical Definition

*A port number is a 16-bit number (0–65535) used by the Transport Layer (TCP/UDP) to route data to the correct process*.

### 🧠 Simple Explanation

- IP Address tells which device
- Port Number tells which application inside that device

### 🔢 Example

`192.168.1.10:80`

- `192.168.1.10` → Device
- `80` → Port number (HTTP service)
