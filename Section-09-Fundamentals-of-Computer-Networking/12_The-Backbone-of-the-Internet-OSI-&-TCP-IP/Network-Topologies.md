# ✅ Network Topologies

## 📌 Definition  
A **Network Topology** defines how devices (nodes) are connected and communicate within a network.

👉 **Node:**  
Any device capable of sending and receiving data in a network (e.g., computer, router, printer).

---

## 📊 Types of Network Topologies  

### 0️⃣ Point-to-Point  
- Direct connection between **two nodes**  
- Common in **PAN (Personal Area Network)**  

✔ Simple and fast  
❗ Not always included in all textbooks  

---

### 1️⃣ Bus Topology  
- All nodes are connected through a **single central cable (bus)**  

✔ Simple and low cost  
❌ If the main cable fails → entire network stops  

---

### 2️⃣ Ring Topology  
- Nodes are connected in a **circular (ring) structure**  
- Data travels through each node  

✔ Organized structure  
❌ Devices cannot directly communicate → must pass data through other nodes  

---

### 3️⃣ Star Topology  
- All nodes are connected to a **central device (hub/switch/router)**  

✔ Easy to manage and widely used (LAN)  
❌ If central device fails → entire network fails  

---

### 4️⃣ Mesh Topology  
- Every node is connected to **every other node**  

✔ Highly reliable (multiple paths available)  
❌ Expensive (requires many connections/wires)  

---

### 5️⃣ Tree Topology  
- Hierarchical structure (like a **parent-child tree**)  

✔ Used in large networks (e.g., universities, organizations)  
✔ Scalable and organized  

---

### 6️⃣ Hybrid Topology  
- Combination of **two or more topologies**  

✔ Flexible and scalable  
✔ Used in real-world networks (e.g., the Internet)  

---

## 💡 Key Points (Exam Focus)

- Bus → Single cable (cheap but risky)  
- Ring → Circular flow (no direct communication)  
- Star → Central device (most common in LAN)  
- Mesh → Highly reliable but costly  
- Tree → Hierarchical structure  
- Hybrid → Combination (used in real-world networks)
